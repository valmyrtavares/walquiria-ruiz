# Walquiria Ruiz Atelier — Alta Costura Sob Medida

Site institucional e portfólio de alta costura e alfaiataria feminina sob medida, desenvolvido com arquitetura **Mobile-First**, estética de editorial de moda (*Vogue/Harper's Bazaar*), tipografia refinada e integração direta com WhatsApp.

---

## 🎨 Identidade Visual & Conceito
- **Cor de Fundo:** Marfim linho texturizado (`#FAF8F5`) extraído do logotipo original.
- **Cor Primária:** Midnight Navy (`#0E1F38`).
- **Cor de Destaque:** Dourado Champagne (`#C5A880`) inspirado no fio de ouro e na agulha da alfaiataria.
- **Tipografia:** *Cormorant Garamond* (alta joalheria/costura) e *Montserrat* (moderno e legível).

## 🚀 Como Hospedar na Vercel

O projeto foi construído em **HTML5 Semântico, CSS3 Moderno e JavaScript Puro**, sem necessidade de build ou compilação. Isso garante nota máxima no Google Lighthouse, carregamento em menos de meio segundo e hospedagem gratuita e imediata na Vercel.

### Opção 1: Via GitHub (Recomendado)
1. Suba esta pasta para um repositório no seu GitHub.
2. Acesse [vercel.com](https://vercel.com) e clique em **"Add New Project"**.
3. Importe o repositório.
4. Clique em **"Deploy"** (a Vercel detectará o projeto estático automaticamente com as regras do `vercel.json`).

### Opção 2: Pelo Terminal
Na pasta do projeto, execute:
```bash
npx vercel
```
Siga as instruções rápidas na tela para publicar em produção.
